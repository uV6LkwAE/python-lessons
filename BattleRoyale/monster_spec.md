# monster.py 仕様

## 概要

ランダムに5体のモンスターを生成し、RPG風のステータス、レベル、オッズ、攻撃ダメージ、会心ダメージ、回避判定を確認するプログラム。

戦闘を最後まで行うゲームではなく、1回分の攻撃判定を表示して終了する。

## モンスター

モンスター名は以下の5体。

- スライム
- ゾンビ
- ゴースト
- ドラゴン
- デーモン

各モンスターは以下のステータスを持つ。

| ステータス | 内容 |
|---|---|
| `HP` | 体力 |
| `MP` | 魔力 |
| `ATK` | 攻撃力 |
| `DEF` | 防御力 |
| `SPD` | 素早さ |
| `MAG` | 魔法力 |
| `lv` | レベル |
| `odds` | オッズ |

`HP`, `MP`, `ATK`, `DEF`, `SPD`, `MAG` は、それぞれ10から50のランダムな整数で決まる。

## レベル

レベルは6つの基本ステータスの合計を10で割った整数値。

```text
lv = (HP + MP + ATK + DEF + SPD + MAG) // 10
```

## オッズ

レベルが高いモンスターほど上位として扱う。

1. レベルの高い順に並べる。
2. 最上位の基準オッズは2。
3. 同じレベルのモンスターが複数いる場合は、順位の平均をオッズにする。
4. 平均値が整数なら整数として保存する。

## 攻撃者と防御者

モンスター一覧から攻撃者をランダムに1体選ぶ。

その攻撃者を除いた残りのモンスターから、防御者をランダムに1体選ぶ。

## 通常ダメージ

攻撃者の `ATK` と防御者の `DEF` から基準値 `D` を計算する。

```text
D = int((ATK - DEF / 2) / 2)
```

ダメージは `D` によって変わる。

| 条件 | ダメージ |
|---|---|
| `D < 2` | 0から1のランダム |
| `2 <= D < 9` | `D - 2` から `D` のランダム |
| `9 <= D` | `D * 7 / 8 + ((D / 4 + 1) * 0から255のランダム) / 256` |

最終的なダメージは整数に変換する。

## 会心ダメージ

攻撃者の `ATK` をもとに計算する。

```text
critical = int(ATK * random(55から65) / 64)
```

## 回避判定

防御者の `SPD` が45以上なら `True`、45未満なら `False`。

`can_avoid()` は判定結果のbool値だけを返す。

このファイルでは呼び出し元で回避できるかどうかを表示するだけで、ダメージの増減やHPの減少は行わない。

## 実行結果

実行すると以下を表示して終了する。

- レベル順の一覧
- 各モンスターのステータス
- 攻撃者
- 防御者
- 通常ダメージ
- 会心ダメージ
- 防御者の `SPD`
- 防御者の回避判定
