# monster2.py 仕様

## 概要

5体のモンスターがランダムなステータスで戦う、賭け要素付きのRPG風バトルゲーム。

プレイヤーは最初に応援するモンスターと賭け金を選ぶ。戦闘はランダムに選ばれた攻撃者と防御者で進み、最後の1体になったモンスターが勝利する。

## モンスター

登場モンスターは以下の5体。

- スライム
- ゾンビ
- ゴースト
- ドラゴン
- デーモン

各モンスターは以下のステータスを持つ。

| ステータス | 内容 |
|---|---|
| `HP` | 体力。0以下になると戦闘不能 |
| `MP` | 魔法や補助技で消費する |
| `ATK` | 通常攻撃、必殺技、会心ダメージに使う |
| `DEF` | 通常攻撃、魔法攻撃の軽減に使う |
| `SPD` | 回避判定に使う |
| `MAG` | 魔法攻撃に使う |
| `LV` | ステータス合計から計算されるレベル |
| `odds` | 賭け成功時の倍率 |
| `condition` | 状態異常の一覧 |
| `condition_count` | 状態異常の継続ターン数 |

基本ステータス `HP`, `MP`, `ATK`, `DEF`, `SPD`, `MAG` は10から50のランダムな整数。

## レベル

```text
LV = (HP + MP + ATK + DEF + SPD + MAG) // 10
```

## オッズ

レベルが高いモンスターほど低いオッズになる。

1. レベルの高い順に並べる。
2. 最上位の基準オッズは2。
3. 同じレベルのモンスターが複数いる場合は、順位の平均をオッズにする。
4. 平均値が整数なら整数として保存する。

## ゲーム開始

1. 全モンスターを生成する。
2. レベルとオッズを計算する。
3. 各モンスターに状態異常管理用の `condition` と `condition_count` を追加する。
4. プレイヤーが賭けるモンスター名を入力する。
5. プレイヤーが賭け金を入力する。

## ターン進行

各ターンで以下を行う。

1. 毒や眠りの状態異常処理を行う。
2. HPが0以下のモンスターを戦闘不能にする。
3. 残り1体なら勝敗判定を行う。
4. 攻撃者と防御者をランダムに選ぶ。
5. 攻撃者がプレイヤーの選んだモンスターならコマンドを選ぶ。
6. それ以外のモンスターなら通常攻撃を行う。
7. HPが0以下のモンスターを戦闘不能にする。
8. 残り1体なら勝敗判定を行う。
9. 続行する場合はEnterで次のターンに進む。

## 攻撃者と防御者

生存しているモンスターから攻撃者をランダムに1体選ぶ。

その攻撃者を除いた残りのモンスターから、防御者をランダムに1体選ぶ。

## 通常攻撃

通常攻撃では、会心判定を先に行う。

会心が出た場合は会心ダメージを与える。

会心が出なかった場合は通常ダメージを与える。

元コード上、通常攻撃では回避判定や攻撃力アップ処理は実質使われていない。

## 通常ダメージ

```text
D = int((ATK - DEF / 2) / 2)
```

| 条件 | ダメージ |
|---|---|
| `D < 2` | 0から1のランダム |
| `2 <= D < 9` | `D - 2` から `D` のランダム |
| `9 <= D` | `D * 7 / 8 + ((D / 4 + 1) * 0から255のランダム) / 256` |

防御者に `debuff` がある場合、ダメージ計算時だけ `DEF` を20%ずつ下げる。`debuff` が2なら2回下げる。

## 会心

会心率は50分の1。

```text
random(1から50) == 1
```

会心ダメージは以下。

```text
critical = int(ATK * random(55から65) / 64)
```

## 回避

防御者の `SPD` が45以上、かつ3分の1の確率で回避成功。

```text
SPD >= 45 and random(1から3) == 1
```

必殺技と魔法攻撃で使われる。

## プレイヤーコマンド

プレイヤーが選んだモンスターが攻撃者になったとき、以下の行動を選べる。

| 番号 | 行動 |
|---|---|
| 1 | 通常攻撃 |
| 2 | HPを10回復 |
| 3 | 必殺技 |
| 4 | 魔法の選択 |
| 5 | 毒攻撃 |

## 回復

通常回復はゲーム全体で2回まで。

選んだモンスターの最大HPを超えない範囲で、HPを最大10回復する。

## 必殺技

必殺技は2分の1の確率で成功する。

成功した場合、通常ダメージの2倍を与える。

失敗した場合、ダメージは発生しない。

攻撃者に `POWER_UP` がある場合、ダメージを1.5倍にし、残り回数を1減らす。

防御者が眠っていない場合、回避判定が成功すると攻撃は当たらない。

攻撃が当たった場合、防御者の `debuff` は解除される。

防御者が眠っていた場合、攻撃が当たると眠りが解除される。

## 魔法

魔法選択では以下を選べる。

| 番号 | 魔法 |
|---|---|
| 1 | 魔法攻撃 |
| 2 | 回復魔法 |
| 3 | 攻撃力アップ |
| 4 | 防御力ダウン |
| 5 | 眠り攻撃 |

### 魔法攻撃

MPを10消費して魔法ダメージを与える。

```text
D = int((MAG - DEF / 3) / 2)
```

| 条件 | ダメージ |
|---|---|
| `D < 2` | 2から3のランダム |
| `2 <= D < 9` | `D` から `D + 2` のランダム |
| `9 <= D` | 通常ダメージと同じ高ダメージ式 |

防御者が眠っていない場合、回避判定が成功すると攻撃は当たらない。

攻撃が当たった場合、防御者の `debuff` は解除される。

防御者が眠っていた場合、攻撃が当たると眠りが解除される。

### 回復魔法

入力したMP消費量と同じだけHPを回復する。

選んだモンスターの最大HPを超える場合は実行できない。

### 攻撃力アップ

MPを15消費する。

使用者に `POWER_UP = 2` を付与する。

次の2回分の対象攻撃でダメージが1.5倍になる。

### 防御力ダウン

MPを15消費する。

使用者以外のモンスターに `debuff` を付与する。

すでに `debuff` がある場合は最大2段階まで増える。

### 眠り攻撃

MPを20消費する。

使用者以外の各モンスターを40%の確率で眠り状態にする。

## 毒攻撃

毒攻撃はゲーム全体で2回まで。

70%の確率で防御者を毒状態にする。

## 毒状態

毒状態のモンスターは、ターン開始時に最大HPの10%分のダメージを受ける。

毒の継続ターン数に応じて自然解除される。

- 5ターン以下の場合、`継続ターン数 * 10%` の確率で解除
- 6ターン以上の場合、50%の確率で解除

## 眠り状態

眠り状態のモンスターは、継続ターン数に応じて自然解除される。

- 3ターン以下の場合、`(継続ターン数 + 2) * 10%` の確率で解除
- 4ターン以上の場合、50%の確率で解除

眠っている防御者は、必殺技や魔法攻撃で回避判定を行わない。

## 勝敗

HPが0以下になったモンスターは戦闘不能になり、戦闘から除外される。

残り1体になった時点で勝者が決まる。

プレイヤーが賭けたモンスターが勝った場合、以下を賞金として表示する。

```text
賞金 = 勝者のodds * 賭け金
```

それ以外の場合は賭け失敗。
