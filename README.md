# Python Lessons

Python 授業用のサンプル実装例と課題資料をまとめるリポジトリです。

## 注意

- 講師が指定した仕様と、サンプル実装が一部ずれている場合があります。
- 授業の進行や生徒の理解度に合わせて、内容を継続的に修正します。
- このリポジトリのコードは、完成品としてではなく学習用の参考実装として利用します。

## TA 向け

- 生徒のコードとこのリポジトリの実装が一致しているとは限りません。
- 指導時は、まず講師が出した仕様と生徒本人の実装方針を確認してください。
- サンプルコードをそのまま正解として扱わず、考え方の参考として使ってください。
- 誤りがある場合はPRまたは直接お知らせください。

## 生徒向け

- このリポジトリは、課題を進めるための参考資料です。
- まずは自分で考えて実装し、詰まったときに考え方を確認するために使ってください。
- コードをそのまま写すのではなく、なぜその処理が必要なのかを理解することを重視してください。
- 授業で指定された仕様と違う場合は、授業中の指示を優先してください。
